# Mock responses for the web app

One file per FastAPI endpoint, generated by calling the real backend (CsvRepo,
`cd backend && uvicorn app.main:app --port 8000`). The frontend can use these until it
points at `VITE_API_URL`.

- `predict_task_time.json` — `POST /predict/task-time` with
  `{"task_ids": ["T-SH-2026-08-30-M02-N-1", … "T-SH-2026-08-30-M02-N-6"]}` — the 6 tasks of
  the future-day night shift `SH-2026-08-30-M02-N` (operator OP08, machine M02).
- `operator_efficiency.json` — `GET /operators/OP05/efficiency` with no query params:
  default `as_of` = latest completed task date (`2026-08-29`); OP05 has the `novice`
  personality and the response includes 2 training recommendations.
